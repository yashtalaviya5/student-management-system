# Student Management System

A simple full-stack Student Management System developed as part of a technical test.

## How to Run

### Install dependencies

Run from the project root:

npm install

Then install frontend dependencies:

cd frontend
npm install

Then install backend dependencies:

cd ../backend
npm install

## Environment Variables

Create a `.env` file inside the backend folder:

PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/student_management

## Start the Project

From the root folder:

npm run dev

Frontend:

http://localhost:5173

Backend:

http://localhost:5000

## Database

MongoDB is used to store users and student records.
